# 插件安装交互

共享协议定义官方身份、卡片展示字段和启用作用域。桌面与手机只显示卡片、提交安装或跳过；首个有效答复、持久化写入及工具结果归 CLI 所有。不支持卡片的连接只能读取兼容的会话投影。

插件自动推荐开关复用应用设置与运行时偏好同步，默认关闭；设置行只提交偏好，不持有独立业务状态。关闭时不给下一次对话输入暴露搜索和推荐工具，明确请求也不能调用；设置页手动安装和已展示卡片的确认不受影响。

翻译表在目录读取和交互发布时由同一裁剪器限制条目数、键与文本长度、序列化字节数；协议校验拒绝超限载荷。保留所有界面语言及默认文本，事件与快照共用已裁剪字段。

新安装默认使用 `action=install, scope=workspace`：卡片明确授权安装并在当前工作区启用。包安装仍复用用户存储；已有禁用插件仅启用当前工作区。历史 user 卡片保持原语义，CLI 重校验作用域，不能静默扩大确认范围。
