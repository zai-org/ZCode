## 审查补充：Windows 子进程归属设计待完成

- Windows 上“启动器先退出、后代进程仍运行”的调用尚未完整解决。现有 `taskkill /T` 依赖根 PID 仍在，不能把本次 macOS POSIX 进程组回归推断为 Windows 已具备同样的收尾保证。
- 后续须先确认 Windows 的稳定进程归属方案，再验证超时和取消时整个调用已停止，独立配置和 usage 标记不会先于仍存活的后代释放。不能以固定等待或仅检查根 PID 退出代替验证。
- 本次明确不新增未经原生验证的 Win32 Job Object 基础设施；本节记录已知未完成的设计与验证项，不是单纯“未执行测试”。本票继续为 `ready-for-human`，没有执行 Windows 或其他目标平台验收。
