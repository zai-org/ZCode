# 09 — 官方包转换工具与 macOS arm64 资源包

Status: done

## Parent

[01 — 桌面文档工具预装：LibreOffice](01-libreoffice-preinstall.md)

## What to build

做一个工程工具，把 LibreOffice 官方安装包转换成符合 02 契约的资源包；先产出并在本机充分验证 macOS arm64 的资源包。

- 工具流程（spec“资源制作、发布和本机安装”）：下载或读取指定版本的官方包 → 核对官方 GPG 签名 →
  从 dmg 中取出 `.app` → 加入随包中文字体（放在这份 LibreOffice 自己的字体目录）、许可说明和官方源码获取方式 →
  打成统一的归档 → 输出清单条目（大小、SHA-256、入口、必需文件、运行检查）。
- 不自行编译，不修改官方二进制。工具的结构要便于 10 增加其他平台。
- 选定随包中文字体，至少一款无衬线、一款衬线，并确认字体许可允许随包分发。
- 新增的内部发布脚本按开源约束加入导出排除清单。

## Acceptance criteria

- [x] 工具对同一份官方包重复运行，产出相同的归档和清单条目。
- [x] 资源包通过 02 契约的运行时校验；签名不符的官方包被拒绝。
- [x] 在本机非管理员用户目录解压后可以直接运行，不出现 Gatekeeper 等系统弹窗；`.app` 的签名有效，符号链接和可执行权限完整。
- [x] 用独立配置完成 Word、PPT 转 PDF：文档指定的中文字体在系统中存在时使用系统字体，不存在时使用随包中文字体，没有缺字方框。
- [x] 字体名称、来源和许可，以及 LibreOffice 的许可说明，都已记录在资源包和 spec 01 中。
