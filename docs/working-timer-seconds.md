# 工作中计时显示

## 当前契约

运行中的计时显示整秒，每 1000ms 刷新，例如中文 `13 秒`、英文 `13s`。按已完整经过的秒向下取整，再拆分时、分、秒。完成耗时保持原有格式。

ChatLoading 是本地展示时钟的唯一持有者：上游 `initialElapsedMs` 校准本轮耗时基准，`performance.now()` 补足真实经过时间。上游更新不重建计时器；同轮校准不得让计时倒退。停止或卸载时清理计时器，重新开始时使用新基准。桌面和手机 Web 共用组件，不新增协议、持久化或远端时钟。

```text
上游耗时 → 校准基准 → 稳定的 1000ms 刷新 → 整秒
停止 / 卸载 → 清理刷新
```

2026-10-30 曾改为整秒、1000ms 刷新。旧 effect 依赖上游耗时，每次变化都会取消并重建计时器。上游更新快于刷新周期时，回调一直无法执行。2026-11-03 修复计时停滞，解除上游更新与计时器生命周期的耦合；显示使用整秒。

## Orbs Z 加载图标

“工作中”文字使用普通字重 `font-normal`，复用 `animated-gradient-text animated-gradient-text-foreground`，与思考、工具调用使用相同的渐变颜色和 4 秒扫光周期，不维护专用文字扫光样式。整秒计时与 Orbs Z 图标独立保持原有行为。

左侧采用 Orbs Z：旋转点阵球逐渐聚成点阵 Z，再散回球体，周期 8.24 秒：先旋转球体 5 秒，再用 1.296 秒聚成 Z、停留 0.864 秒、用 0.792 秒散回球体，余下 0.288 秒保持球体后进入下一轮。沿用设计提供的点坐标、球面分布、深度透明度和弧线插值；球体半径从 7.5 调为 8.5，Z 点阵在原字形内按 2px 网格重采样，使用 28 点：圆点直径 1px，相邻横纵网格点之间净空 1px，字形断笔处保留更大空隙；球面独立保持 105 个采样点、半径 8.5 和每三个点显示一个的原有分布；28 个 Z 点均匀映射到球面索引，其余点在聚成 Z 时淡出、回到球体时恢复；20px SVG 下球体与 Z 圆点直径统一为 1px（半径 0.5），球体仅以透明度表达深度，旋转角速度为 0.8πrad/s，即每 2.5 秒一圈，不改变 5 秒球体停留时长。20px SVG 在 16px 图标槽内居中，保持文字对齐。颜色通过 `text-brand` 与 currentColor 跟随当前主题：Zai Light 为纯黑，Zai Dark 为纯白；球面深度透明度保持不变。逐帧仅更新 SVG 圆点属性，不触发 React 状态更新。每个实例独立持有动画帧，卸载时取消；减少动态效果模式显示静态 Z，并响应设置变化。整秒计时独立运行。

## 可重复验收

- 真实组件初始 13000ms，上游每 50ms 推进耗时，持续 2 秒：显示持续增加，刷新计时器保持一个，不能停在 13 秒。
- 上游停止更新后，本地计时继续推进；上游返回较小耗时不能导致同轮倒退，较大耗时应校准。
- 停止后没有计时器；同一组件重新运行或重新挂载时使用新的初始耗时。
- 检查 0、999、1000、59949、59950、60000、3599950、4673400ms 的整秒、分与小时进位，中英文单位沿用国际化格式。
- 桌面与手机视口、Zai Light / Zai Dark 下观察 Orbs Z 完整循环与计时。同屏多个实例动画独立；减少动态效果模式字形可见，无循环动画。

受控组件验收与桌面/手机端到端验收分别报告，不互相替代。
