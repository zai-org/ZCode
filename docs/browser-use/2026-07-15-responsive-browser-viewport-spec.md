## 工具栏选中态

- “自由尺寸”和“选择元素”启用时，统一使用 `bg-accent text-icon-blue`：蓝色图标配合主题对应的蓝色底色，避免灰色选中态与普通悬停混淆。
- 悬停在已启用按钮上时保留同一蓝色前景和底色；取消后恢复普通 ghost 按钮样式。
- 保留现有 `aria-pressed`、提示文案、禁用态、按钮尺寸及点击行为；人类 Browser 与 Agent Browser Use 共用此样式。
- 视觉验收使用真实 `BrowserToolbar`，覆盖 Zai Light / Zai Dark、宽屏 / 390px 窄宽度、中英文，以及未选中、选中、悬停和取消。Web / 手机端不因此新增内置浏览器能力。

  -> 只有用户 toggle/input/drag 或显式 Agent viewport set/reset 才改变尺寸

browser.tabs.list()
  -> BrowserGuestManager 按 tab 读取实际 CSS viewport
  -> BrowserTabSummary.viewport
  -> BrowserTabInfo.viewport
  -> tabs.get(info.id).viewportSize()

tab.screenshot()
  -> per-tab screenshot in-flight guard
  -> Page.getLayoutMetrics 只选取 CSS clip，忽略 legacy backing/CSS 比例
  -> CDP Page.captureScreenshot(scale=1, captureBeyondViewport=false for viewport capture)
  -> read PNG IHDR dimensions
  -> equals target CSS clip: return first capture
  -> uniform mismatch: adjustedScale = firstScale × targetSize / actualSize
  -> retry Page.captureScreenshot once, choose result closer to target
  -> host→main 30s 子预算
  -> 成功：清理 in-flight；自由尺寸下输出像素与 CSS viewport 1:1
  -> 外层超时：返回结构化 timeout；底层 settle 前的新截图明确失败且不再次 dispatch
  -> late completion：清理 in-flight，后续截图恢复

guest wheel（仅自由尺寸宿主消费）
  -> guest 内部存在对应方向可滚动祖先：保留给网页
  -> guest 内部无可滚动祖先，且网页未 preventDefault
  -> fixed preload `sendToHost(wheel-boundary, deltaX/deltaY)`
  -> embedder `<webview>` `ipc-message`
  -> responsive canvas `scrollBy({ left: deltaX, top: deltaY })`
