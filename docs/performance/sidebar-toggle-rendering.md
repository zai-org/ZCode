# 左右侧栏开关的布局开销

## 范围与约束

优化工作区左侧导航和右侧 Side Pane 的展开、收起。入口、标签归属、宽度记忆、键盘操作及内容生命周期沿用现有契约。手机继续使用抽屉。底部终端复用同一尺寸控制 hook，纳入回归。

左右侧栏必须保留原有的 200ms ease-out 展开、收起动画：左侧 width + opacity，右侧 flex-grow + opacity。主会话区域随侧栏尺寸连续变化，不能用尺寸瞬间切换、仅透明度或裁剪显露替代。2026-11-02 的“尺寸直接到位”策略撤回；交互等价是性能优化的前提。

右侧尺寸过渡只在显式开关时启用，动画结束或取消后清理临时样式；拖动和未触发自动收起策略的原生窗口 resize 不使用尺寸动画；窗口过窄触发的既有自动收起仍属于开关，不改变原策略。右侧内容在开关期间保持展开宽度，避免 Tabs / Browser / Terminal 逐帧压缩、换行后才淡出。临时宽度仅属于动画展示层，不复制开关业务状态，不用超时决定完成。快速反向沿用当前插值尺寸，最终状态以最后一次开关为准。

保留项目树 memo、稳定回调以及标题栏等与侧栏开关无关的既有优化。问候语绘制前字号适配继续生效，不能恢复 RAF → React 字号状态链路。系统减少动画时直接收敛；完整视图的内容定位、手机抽屉 transform / 堆叠布局和 Browser 截图 surface 不受临时宽度影响。

```text
按钮 / 快捷键 / 工具打开 → useAppPanels（既有开关 owner）
                              ↓
                shell 提交目标尺寸与显隐
                   ├─ 左侧：width + opacity 过渡 200ms
                   ├─ 右侧：Panel 尺寸 + opacity 过渡 200ms
                   │         └─ 动画完成 / 取消 → 释放临时内容宽度
                   └─ 手机：既有抽屉 transform
输入框：ResizeObserver → 绘制前适配字号（保留原防抖修复）
```

Panel 命令仍须在库注册约束后执行；取消旧帧回调，快速反向操作以最后一次开关为准。首次可见挂载不能覆盖已保存宽度。收起和打开不能重建已有标签或终端。

布局回归以草稿投影已就绪为前置条件。冷启动预热尚未完成时的 scope 回填与面板偏好同步属于独立状态路径，不计为本次性能覆盖；测试应等待 `data-session-lifecycle=ready` 和非空投影序号，不使用固定延时替代初始化信号。

## 可重复验收

### 富内容会话（STF05–07）

侧栏连续尺寸动画期间，Markdown 表格直接跟随当前可用宽度，不能对每一帧的目标宽度再启动一段尺寸过渡。用户主动展开、收回表格滚动区域时仍保留原尺寸动画。表格横向滚动、左右借位、sticky 滚动条、复制、下载和预览能力不变。尺寸通知合并处理，尺寸变化不能无条件带动工具栏重新渲染。

时间线仍负责虚拟行高度与滚动锚点。保持底部跟随、用户离底阅读和搜索定位的既有语义，不能通过冻结正文、关闭换行或延后到动画结束才校正位置来提高帧率。同步提交只用于确有必要的高度提交屏障，不能直接删除现有防跳动屏障。

实现约束：普通表格由 CSS 百分比跟随 frame；增强模式保留借位几何计算。只有表格模式按钮启用临时尺寸过渡，按真实动画完成或取消清理；外层尺寸变化、横向借位和卸载终止该过渡。滚动条 thumb 的几何只更新对应节点，工具栏仅随模式、语言和操作回调变化。尺寸测量复用同一组 root/frame/viewport/table observer，避免重复通知。

```text
侧栏每帧尺寸 → 表格跟随当前宽度 → 同一组 observer 更新滚动范围与阴影
            → 时间线测高 → 对比最近一次已提交的行高、坐标、总高度
                          ├─ 有差异：同步提交几何 → 按既有滚动归属校正
                          └─ 无差异：省去同步 React 提交
表格模式按钮 → 临时 200ms 尺寸动画 → 完成 / 取消 / 外部 resize → 清理
```

比较基准必须是已提交 DOM 几何；虚拟列表缓存可能提前变化，不能只比较缓存就删掉绘制前的提交屏障。用户离底时仍由现有阅读位置逻辑持有滚动权。
