## 状态定义

| 状态                          | 含义                                              |
| ----------------------------- | ------------------------------------------------- |
| `blocked-by-product-decision` | 产品结论未确认，只能保留测试落地计划              |
| `ready-to-write`              | 产品结论已确认，可以开始写 E2E                    |
| `implemented`                 | 已有独立 E2E 自动化证据，可以回写 coverage matrix |
| `ignored`                     | 产品确认当前版本不覆盖                            |
| `invalid`                     | 产品确认该组合被前置规则剪掉                      |

## 与覆盖矩阵的状态关系

审计脚本会把本路线图和主路径 / fault coverage matrix 机械对齐：

| Coverage status                 | Roadmap status                |
| ------------------------------- | ----------------------------- |
| `undefined` / `decision-needed` | `blocked-by-product-decision` |
| `missing` / `planned`           | `ready-to-write`              |
| `failing` / `partial`           | `implemented`                 |
| `ignored`                       | `ignored`                     |
| `invalid`                       | `invalid`                     |

当某条 case 在 coverage matrix 里变成 `covered` 后，它就不再需要出现在本路线图里。
