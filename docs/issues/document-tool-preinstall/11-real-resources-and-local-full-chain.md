## What to build

把资源包交给资源发布方部署到 CDN，然后把真实地址写进内置清单。在本机 macOS arm64 上，用真实资源验证从后台准备到文档交付的完整流程。

- 把 09 的 macOS arm64 资源包，以及 10 已产出的其他包（如果已完成），连同校验信息交给资源发布方部署。
  部署完成后，把真实地址（国内和海外两组 CDN）、大小和 SHA-256 写进 App 内置清单。
- 在本机用真实 CDN 跑完整流程：后台准备 → 原会话继续 → Word、PPT 转换 → 中文显示 → Excel 重算 → 系统版本回退 → 未就绪提示 → 切换目标版本。
- 更新文档类官方插件 spec 的“依赖边界”：LibreOffice 在桌面本机由预装功能提供，其他依赖保持现状。
