## 1. 状态维度

| 维度           | 值                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Backend        | none / iab / extension / cdp / iab+extension / extension 多实例 / all                          |
| 选择入口       | exact id / type alias / default / URL local / URL exact tab / URL host hierarchy / invalid URL |
| Client mode    | desktop-continuous / web-remote-replayable                                                     |
| Workspace      | local / SSH / WSL / Docker / 同 path 不同 identity                                             |
| Runtime        | fresh kernel / warm kernel / timeout reset / sandbox reset / session close                     |
| Tab origin     | agent-created / claimed user tab / unclaimed user tab / restored / stale                       |
| Tab lifecycle  | open / active / background / handoff / deliverable / finalized / closed                        |
| API family     | navigation / playwright / cua / dom_cua / content / clipboard / dev / dialog / capability      |
| Security       | read-only / preapproved / action-confirm / denied / attempted bypass                           |
| Backend health | healthy / unavailable / handshake timeout / disconnect / reconnect / stale generation          |
| Result         | direct value / bytes/image / response meta / structured error / uncertain side effect          |

完整 Cartesian product 不可执行，采用边界分组、pairwise 和风险优先组合。任何剪枝都不能删除 backend identity、clientMode、workspace identity、安全 deny 或 lifecycle cleanup 的交叉用例。

## 2. 剪枝决策

| 组合                                   | 决策              | 理由                                      |
| -------------------------------------- | ----------------- | ----------------------------------------- |
| Playwright 作为 backend                | 剪枝              | 概念错误；Playwright 是 API family        |
| extension/cdp 在未实现阶段返回 stub    | 禁止              | 会制造假可用性                            |
| mobile 自建 backend runtime            | 剪枝              | 违反 shared-host attachment 约束          |
| relay/main 持有 tab/task 状态          | 剪枝              | 违反远控架构                              |
| remote 仅按 workspacePath 隔离         | 禁止              | 必须 workspaceIdentity/remoteSessionId    |
| 每个 OS × 每个 API method 全量组合     | pairwise          | OS 差异集中在安装/native host/路径/快捷键 |
| 每个 browser version × 每个 locator    | pairwise          | 保留 stable/beta 与关键 locator/action    |
| CDP gated off 时的所有动作             | 只测不可见/不可选 | unsupported member/backend 必须隐藏       |
| action deny 后通过另一 API family 重试 | 必测              | 防绕过核心安全边界                        |

## 10. E2E 晋级门槛

任何 Slice 进入“完成”前：

1. 对应 case 从“待实现”改为自动化用例路径和结果，不只改状态文字。
2. 协议变更必须有 strict schema 正反例、旧调用兼容和端到端 correlation 测试。
3. 交互/远控用例必须标出 desktop continuous 与 web replayable 影响。
4. Extension/CDP 不能用 mock 单独证明完成；至少有真实 Chrome/真实 CDP smoke E2E。
5. API manifest、runtime object graph 和 documentation 必须做 snapshot/contract 一致性测试。
6. 必跑 `pnpm typecheck`、`pnpm lint`，并记录无法覆盖的 OS/签名/远端环境风险。
