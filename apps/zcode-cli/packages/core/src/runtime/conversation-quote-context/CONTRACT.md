# 对话引用上下文

仅登记 `withConversationQuotes` 的现有模型边界，不改变输入持久化或 Bot 投递路径。

- 引用作为材料附加，不混入 canonical 正文或解析为控制命令。
- 引用可带用户批注 `comment` 与子 agent 来源 `agent`；有非空批注时追加一句说明，指明批注是用户针对该段原文的要求，无批注时输出不变。
- Bot 身份、消息顺序及原生 mention 位置用于归属判断，显示名不能授予执行或发送权限。
- 普通最终回答仍由 Host 自动投递；默认不注入 ReplyToChannel 指引或发送引用。
- 函数不修改传入数组和元数据，不拥有可变会话状态或外部 IO。
