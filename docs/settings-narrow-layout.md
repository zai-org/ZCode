# 设置页窄屏 Web 布局

## 背景

手机远控（`/remote`）和手机浏览器宽度约 375–430px。设置页原布局按桌面设计：

- `max-lg` 下左侧导航收成 68px 图标栏，长期占用内容宽度。
- `SettingsRow` 默认布局固定为“文字列 + 192px 控件列”，文字列只剩约 60px，标题和描述被压成每行 2–3 个字。
- 模型设置的供应商标题行固定 `h-8`，连接方式下拉框换行后盖住下方卡片（桌面窄窗口同样发生）；页头操作组被描述挤到换行错位。
- 使用统计趋势图强制显示每个日期刻度，7 个日期在手机宽度和桌面窄窗口下叠字。

## 生效范围：`compact-web`

窄屏样式统一挂在 `packages/ui/src/styles.css` 的 `compact-web` variant 上，条件同时满足：

1. 视口宽度 `< 40rem`（640px）。
2. 根节点没有 `platform-mac-desktop` / `platform-windows-desktop` / `platform-linux-desktop`（桌面 renderer 启动时设置）。

桌面端最小窗口宽度为 480px，只用 `max-sm` 会改变桌面窄窗口布局，因此必须带平台条件。
桌面端任何宽度、宽屏 Web（≥ 640px）的布局都不变（下文“全平台修复”除外）。

`compact-web` 只在 CSS 中使用；不要在 JS 中复制它的判据。需要随宽度变化的 JS 布局参数，应改为由组件按实际尺寸自行适配。

## 行为（仅 `compact-web`）

| 区域                                              | 行为                                                                                                                                                                          |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 设置导航（`SettingsPage`）                        | 页面改为上下两行：顶部是横向滚动导航条，左侧返回按钮，后面是“图标 + 文字”分区按钮，分组之间用竖线分隔；下方内容占满宽度。切换分区时，若导航条横向溢出，把当前分区滚进可见区域 |
| 设置行（`SettingsRow` 默认布局）                  | 可换行 flex：文字列至少 10rem 并优先占满剩余空间；开关、短按钮放得下时在同一行右侧，下拉框、长按钮换到文字下方右对齐，宽度不超出卡片。`wide` 布局沿用原有 `sm` 单列堆叠       |
| 资源页头操作组（`SettingsResourceHeaderActions`） | 保持一行且不被压缩，描述文字在左侧换行                                                                                                                                        |

只调整展示，不改变控件、顺序和交互。

## 全平台修复

以下两处在桌面窄窗口（约 480–600px）同样出错，原因与平台无关，因此不挂 `compact-web`，所有平台和宽度统一生效：

| 区域                                           | 行为                                                                                                                                     |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 模型设置供应商标题行（`ProviderFamilyHeader`） | 最小高度 32px，内容换行时按内容撑开，连接方式下拉框不覆盖下方卡片；不换行时仍是 32px                                                     |
| 使用统计趋势图 X 轴                            | 由 recharts 按实际绘图宽度跳过会重叠的刻度，保留首尾日期（见 [使用统计 spec](ui/settings-usage-stats.md)）；宽屏 30 天视图可显示更多刻度 |

## 验收

- 390px 视口 Web 打开设置页：顶部导航可横向滚动；「常规」「外观」「浏览器控制」的标题和描述按正常行宽换行；模型设置连接方式不与下方卡片重叠；使用统计趋势图日期不叠字。
- 480px 视口并给根节点加 `platform-mac-desktop`（模拟桌面最小窗口）：仍是左侧 68px 图标栏和“文字列 + 192px 控件列”；模型设置连接方式不与下方卡片重叠；趋势图日期不叠字。
- 1280px 宽屏 Web：除趋势图 30 天视图的刻度数量外，布局与修改前一致。
- 深浅主题都检查。
