What's inside

Quiet by default. Loud when it matters.

Three core principles that shape every part of Stratus, from the query language up to the on-call experience.

— 01 / Principle

Routing decisions happen in the data path, not in a UI.

You write the policy as a single expression. Stratus compiles it into the routing layer at deploy time, so traffic decisions don't depend on a control plane being awake at 3 a.m.

— 02 / Tooling

One query language for logs, metrics, and traces.

Stop translating between three different syntaxes when you're already down two coffees and a pager incident.

— 03 / Cost

Per-query billing, not per-ingest.

You pay for what you read. Storage is free up to your retention window — which makes "just keep it in case" actually viable.

— 04 / Operations

The SLO calculator that doubles as a deploy gate.

Burn-rate alerts that map back to error budgets and deployment freezes — built in, not bolted on.

— 05 / Privacy

Field-level encryption on ingest.

PII fields are encrypted before they touch Stratus storage. Compliance is a checkbox, not a six-month integration.
