# 预装工具对话框

- 唯一管理入口是桌面帮助菜单；Web/手机不新增管理入口，远端工作区提示仅管理本机。
- 通过 usePlatform 订阅和查询 utilityProcess 的完整快照，不读磁盘、不保存安装事实。
- 先订阅再查询；收到推送后忽略迟到的初始查询。命令回执不替换快照。
- 按 tools[] 顺序渲染卡片，显示名来自 catalog 投影，用途按 toolId 查国际化资源。
- 每卡仅持有自己的请求 pending/错误与删除确认状态；工具命令携带 toolId，不阻塞其他卡片的操作。
- 自动预装开关使用独立请求状态；保存成功后显示 owner 推送的新值。操作错误在对话框内显示，不弹 Toast。
- 关闭对话框只解除订阅，不取消准备。状态、排队文案、进度、删除确认与占用提示支持中英文及深浅主题。

- 04：卡片按 installed 与 target 分别显示当前版本与目标；更新中或失败仍显示旧版本。删除按钮和占用体积取自 installed，没有目标但已有安装时也可删除。
