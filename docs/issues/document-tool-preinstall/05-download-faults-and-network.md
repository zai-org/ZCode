## What to build

让准备过程在真实网络环境和各种故障下都可靠：失败时报告真实原因，任何情况下都不发布半成品。

- 新增 E2E 用的 HTTP 故障服务：能在下载中途断开连接、限速、返回错误状态码。现有 E2E 只有按文件替换的故障和不注入故障的代理。
- 预装工具进程复用 Host 现有的代理与自定义证书网络适配器，按本机设置构建。
- 下载地址沿用 Source Server 资源的国内／海外双 CDN 候选与排序规则，失败时依次尝试下一个候选。
- 开始下载前检查磁盘可用空间。
- 校验失败一律拒绝发布，也不执行错误资源：摘要不符、包被截断、平台不匹配、缺少必需文件。
- 失败原因映射到 spec 文案表的七类（网络不通、下载中断、磁盘空间不足、文件校验失败、解压失败、运行检查失败、不支持当前系统）。
- App 启动时清理上次异常退出留下的临时安装目录。异常退出留下的未完成文件不被当成安装，也不据此续传。

## Acceptance criteria

- [x] LOP-08：下载中退出 App 再启动，未完成的资源不被视为就绪；遗留的临时目录被清理；开关开启时重新下载，关闭时不自动下载。
- [x] LOP-11：响应中断、网络不可达、磁盘不足或解压失败时，卡片显示对应文案和“重试”；没有半成品可执行路径；已有的完整安装不受损。
- [x] LOP-12：摘要错误、包被截断、平台不匹配或缺少必需文件时，校验失败，不显示就绪，不执行错误资源。
- [x] LOP-13：在带代理和自定义证书的受控环境中能成功下载；主 CDN 不可达时改用备选 CDN；错误可以定位，不隐式绕过配置。
